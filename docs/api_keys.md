# Получение API-ключей

Краткое руководство по регистрации и получению каждого ключа, используемого в проекте.

---

## SX.org Proxy (`SX_PROXY_API_KEY`)

**Используется для:** всех прокси в проекте — RU (скрапинг Avito, 2GIS, Yandex, VK, Flamp, ФССП) и US (OpenAI API).

1. Перейти на [sx.org](https://sx.org/)
2. Зарегистрироваться / войти
3. В личном кабинете: **Developers** → скопировать **API Key**

Проект автоматически создаёт два прокси-порта через API:
- **RU** (country_code=RU) — для скрапинга российских сайтов
- **US** (country_code=US) — для обхода блокировки OpenAI

При первом запуске в логах будут port ID — сохраните их в `.env`:

```env
SX_PROXY_API_KEY=...
SX_PROXY_PORT_ID_RU=12345   # один RU порт (обратная совместимость)
SX_PROXY_PORT_IDS_RU=12345,12346,12347   # рекомендуемый пул RU портов
SX_PROXY_RU_POOL_SIZE=3
SX_PROXY_PORT_ID_US=67890   # появится в логах при первом запуске
```

> **Стоимость:** зависит от тарифа sx.org. Residential-прокси расходуют трафик.

## OpenAI (`OPENAI_API_KEY`)

**Используется для:** AI-суммаризации отзывов (GPT-4o-mini).

1. Перейти на [platform.openai.com](https://platform.openai.com/)
2. Зарегистрироваться / войти в аккаунт
3. Верхнее меню → **API keys** → **Create new secret key**
4. Скопировать ключ — он показывается только один раз
5. Пополнить баланс: **Billing → Add payment method** (минимум $5)

> **Важно:** OpenAI заблокирован в России. Проект автоматически использует US-прокси через sx.org для запросов к API.

> **Стоимость:** GPT-4o-mini ~$0.15 за 1M входных токенов. При 1000 компаний с 200 отзывами ≈ $1–3 за прогон.

```env
OPENAI_API_KEY=sk-proj-...
```

## DaData (`DADATA_API_KEY` + `DADATA_SECRET_KEY`)

**Используется для:** поиска компании по ИНН/ОГРН через ФНС (ЕГРЮЛ/ЕГРИП), нормализация названий, определение типа (ЮЛ/ИП).

1. Перейти на [dadata.ru](https://dadata.ru/)
2. **Регистрация** — только email, подтверждение не нужно
3. После входа: правый верхний угол → **Профиль → API-ключи**
4. Скопировать **API-ключ** и **Секретный ключ**

> **Стоимость:** бесплатный тариф — **10 000 запросов/месяц**. Этого хватает на ~500 компаний в неделю с запасом.

```env
DADATA_API_KEY=...
DADATA_SECRET_KEY=...
```

## Avito Cookies — spfa.ru (`AVITO_COOKIES_API_KEY`)

**Используется для:** обхода антибот-защиты Авито. Сервис генерирует валидные cookies, которые позволяют скрапить без блокировок.

1. Перейти на [spfa.ru](https://spfa.ru/)
2. Зарегистрироваться, пополнить баланс
3. В личном кабинете скопировать API-ключ

> **Стоимость:** ~12₽ за набор cookies, действуют ~12 часов.
> **Без этого ключа** коллектор Avito работает, но может блокироваться.

```env
AVITO_COOKIES_API_KEY=...
```

## SerpAPI (`SERPAPI_KEY`) — опционально

**Используется для:** поиска URL отзывов (Flamp, VK, Отзовик) на этапе обогащения. Fallback при блокировке DuckDuckGo.

1. Перейти на [serpapi.com](https://serpapi.com/)
2. **Sign Up** → подтвердить email
3. В дашборде: **API Key** → скопировать

> **Стоимость:** бесплатный тариф — **100 поисков/месяц**. Платный — от $50/мес.
> **Без этого ключа** система использует DuckDuckGo (бесплатно, но может блокироваться).

```env
SERPAPI_KEY=...
```

## Прокси: устаревший способ (`PROXY_URL` / `PROXY_FILE`)

> **Рекомендуется использовать sx.org** (см. выше). Эти настройки — fallback на случай, если sx.org не настроен.

### Один прокси:
```env
PROXY_URL=http://user:pass@gate.provider.com:10000
```

### Несколько прокси (ротация):
```env
PROXY_FILE=proxies.txt
```

Формат файла (по одному на строку):
```
http://user:pass@host1:port
socks5://user:pass@host2:port
host3:port
```

## Ключи, которые НЕ нужны

| Ключ | Почему не нужен |
|---|---|
| `TWOGIS_API_KEY` | 2GIS-ключ перехватывается из браузера автоматически |
| `FSSP_API_TOKEN` | ФССП работает через парсинг сайта (httpx + BeautifulSoup) |
| `VK_ACCESS_TOKEN` | VK-отзывы собираются через Playwright (публичные группы, m.vk.com) |
