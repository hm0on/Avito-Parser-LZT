# Получение API-ключей

Краткое руководство по регистрации и получению каждого ключа, используемого в проекте.

---

## OpenAI (`OPENAI_API_KEY`)

**Используется для:** AI-суммаризации отзывов (GPT-4o-mini), оценки риска.

1. Перейти на [platform.openai.com](https://platform.openai.com/)
2. Зарегистрироваться / войти в аккаунт
3. Верхнее меню → **API keys** → **Create new secret key**
4. Скопировать ключ — он показывается только один раз
5. Пополнить баланс: **Billing → Add payment method** (минимум $5)

> **Стоимость:** GPT-4o-mini ~$0.15 за 1M входных токенов. При 1000 компаний с 200 отзывами ≈ $1–3 за прогон.

```env
OPENAI_API_KEY=sk-proj-...
```

## DaData (`DADATA_API_KEY` + `DADATA_SECRET_KEY`)

**Используется для:** поиска компании по ИНН/ОГРН через ФНС (ЕГРЮЛ/ЕГРИП).

1. Перейти на [dadata.ru](https://dadata.ru/)
2. **Регистрация** — только email, подтверждение не нужно
3. После входа: правый верхний угол → **Профиль → API-ключи**
4. Скопировать **API-ключ** и **Секретный ключ**

> **Стоимость:** бесплатный тариф — **10 000 запросов/месяц**. Этого хватает на ~500 компаний в неделю с запасом.

```env
DADATA_API_KEY=...
DADATA_SECRET_KEY=...
```

## ФССП (`FSSP_API_TOKEN`)

**Используется для:** проверки исполнительных производств.

1. Перейти на [api.fssp.gov.ru](https://api.fssp.gov.ru/)
2. Нажать **Регистрация** → заполнить форму (email, ФИО, организация)
3. После подтверждения email войти в личный кабинет
4. В разделе **Токены** нажать **Создать токен**
5. Скопировать полученный токен

> **Стоимость:** бесплатно. Лимит — 1 000 запросов/сутки на один токен.

```env
FSSP_API_TOKEN=...
```

## VK Service Token (`VK_ACCESS_TOKEN`)

**Используется для:** поиска отзывов на стенах VK-групп компаний (Stage 2).

1. Перейти на [vk.com/apps](https://vk.com/apps)
2. **Создать приложение** → тип **Standalone** → ввести любое название
3. В настройках приложения перейти в раздел **Настройки**
4. Найти поле **Сервисный ключ доступа** → скопировать

> **Важно:** сервисный ключ (service token) — не требует авторизации пользователя и не истекает. Именно он нужен, не user token.

> **Стоимость:** полностью бесплатно. Лимит — 3 запроса/сек.

```env
VK_ACCESS_TOKEN=...
```

## SerpAPI (`SERPAPI_KEY`) — опционально

**Используется для:** поиска URL отзывов (Flamp, VK, Отзовик). Фолбэк при блокировке DuckDuckGo.

1. Перейти на [serpapi.com](https://serpapi.com/)
2. **Sign Up** → подтвердить email
3. В дашборде: **API Key** в правом верхнем углу → скопировать

> **Стоимость:** бесплатный тариф — **100 поисков/месяц**. Платный — от $50/мес за 5 000 поисков.
> При 1 000 компаний × 3 запроса = 3 000 запросов/прогон → нужен платный тариф.
> **Без этого ключа** система использует DuckDuckGo (бесплатно, но может блокироваться).

```env
SERPAPI_KEY=...
```

## Прокси (`PROXY_URL` / `PROXY_FILE`)

**Используется для:** обхода антибот-защиты Avito и Яндекс.Карт.

Нужны **резиденские прокси** (residential) — дата-центровые почти сразу блокируются Avito.

### Рекомендуемые провайдеры:
| Провайдер | Ссылка | Минимальный план |
|---|---|---|
| Bright Data | brightdata.com | от $15/GB |
| Oxylabs | oxylabs.io | от $15/GB |
| IPRoyal | iproyal.com | от $7/GB |
| Smartproxy | smartproxy.com | от $7/GB |

### Настройка одного прокси:
```env
PROXY_URL=http://user:pass@gate.provider.com:10000
```

### Настройка нескольких прокси (ротация):
1. Скопировать `proxies.txt.example` → `proxies.txt`
2. Заполнить своими прокси (по одному на строку)
3. Указать путь в `.env`:
```env
PROXY_FILE=proxies.txt
```

> Файл `proxies.txt` добавлен в `.gitignore` — не попадёт в репозиторий.
